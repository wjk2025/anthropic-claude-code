Welcome to O365 Task Tracker

Connect your Microsoft account to automatically track tasks from your email.

1

Register an Azure App

Go to Azure App Registrations and click New registration.

  • Name: Task Tracker
  • Account type: Accounts in any organizational directory and personal Microsoft accounts
  • Redirect URI: Web → copy the value from the field below
2

Get Your Credentials

After creating the app, copy the Application (client) ID and Directory (tenant) ID from the overview page. Then go to Certificates & secrets → New client secret and copy the secret value.

3

Add API Permissions

Go to API permissions → Add a permission → Microsoft Graph → Delegated permissions and add: Mail.Read, Mail.ReadBasic, User.Read

4

Paste Your Credentials Below
